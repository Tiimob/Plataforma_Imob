# Plataforma Even Vendas

Central interna de acessos, credenciais, suporte e orientações para a operação **Even Vendas**.

> Versão atual: **5.0.0** — atualização de 25/08/2026

## O que mudou na versão 5.0.0

- **Even Vendas** passa a ser a única empresa da plataforma.
- A seleção entre empresas foi removida.
- A interface e a base de conhecimento foram revisadas para o contexto único da Even Vendas.
- E-mail corporativo padronizado no domínio `@evci.com.br`.
- Hypnobox padronizado para `https://even.hypnobox.com.br`.
- Webmail padronizado para `http://webmail.evci.com.br`.
- Nova identidade visual **Even Vendas** aplicada à plataforma.
- Favicon e ícones do aplicativo atualizados com a nova marca.
- Chamados de suporte identificam automaticamente a empresa como **Even Vendas**.
- Cache do PWA atualizado para evitar carregamento da versão anterior.

## Principais recursos

- Geração de e-mail corporativo a partir do apelido.
- Acesso rápido ao Webmail, Hypnobox, Portal do Corretor e SIGAV.
- Assistente Imob com base de conhecimento local.
- Orientações sobre Hypnobox, SkyMail/Webmail, Google Authenticator, Portal do Corretor e SIGAV.
- Regras internas sobre FAC, carteira, gerente e atualização de clientes.
- Formulário para geração de e-mail de suporte.
- PWA instalável, testes automáticos e relatório local.

## Publicação no GitHub Pages

Substitua os arquivos atuais do repositório pelos arquivos desta versão, mantendo todos no mesmo nível da pasta do projeto.

Depois da publicação, use `Ctrl + F5` caso o navegador ainda exiba uma versão anterior.
