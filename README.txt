MELHORIAS DESTA VERSÃO:
- Botões “Sim, ajudou” e “Não ajudou”.
- Grau de confiança: respostas ambíguas pedem confirmação.
- Contexto das últimas mensagens durante a sessão.
- Perguntas sem resposta e avaliações salvas no navegador.
- Página relatorio-local.html para consultar e exportar os dados locais.
- Orientações relacionadas após as respostas.
- Tempo de análise variável, mantendo aproximadamente 4 a 5 segundos.
- Plataforma instalável no celular/computador.
- Versão da base visível no rodapé.
- Página testes.html para validar perguntas importantes.
- Melhorias de acessibilidade e aviso para não informar dados sensíveis.
- Correção visual do hover das sugestões do chat.
- Ícone do navegador e do aplicativo atualizado com o logotipo EVEN.

LIMITAÇÃO:
Sem servidor, banco de dados ou aplicação externa, os registros NÃO são centralizados.
Cada computador ou celular armazena apenas os próprios registros. O relatório local
não permite acompanhar automaticamente as conversas feitas em outros dispositivos.
